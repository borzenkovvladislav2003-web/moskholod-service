# Парсер и мониторинг чатов ЖК Москвы (Оффер 1 Сергей)

Этот модуль решает ключевой вопрос клиента:  
**«Откуда взять первые 5–15 живых целевых заявок на тесте без рекламного бюджета?»**

## 1. Как это работает
В Москве в каждом жилом комплексе (ЖК) и районе есть активные Telegram-чаты жильцов (от 500 до 5 000 человек в каждом чате).
Каждую неделю у жителей ломается техника (течет холодильник, намерзает лед, не морозит компрессор). Жители пишут в чат: *«Соседи, посоветуйте хорошего мастера по холодильникам срочно!»*.

Скрипт в режиме реального времени:
1. Сканирует сообщения в открытых чатах ЖК Москвы.
2. Фильтрует спам, рекламу и объявления о продаже б/у техники через стоп-слова.
3. Отлавливает целевой запрос жителя по ключевым словам (*не морозит, потек, мастер по холодильникам, починить холодильник*).
4. Моментально пересылает карточку жителя со ссылкой на его аккаунт прямо в рабочую группу диспетчеров Сергея.
5. Диспетчер пишет жителю в личные сообщения в первые 3 минуты и закрывает заказ на выезд мастера!

## 2. Запуск в демо-режиме (для показа Сергею):
```bash
python3 scripts/lead_parser.py
```
Скрипт запускает наглядный сценарий сканирования московских ЖК и находит 4 целевых запроса.

## 3. Боевой запуск с отправкой в Telegram-чат Сергея:
```bash
python3 scripts/lead_parser.py <BOT_TOKEN> <CHAT_ID>
```
Пример:
```bash
python3 scripts/lead_parser.py 718293847:AAHk... -100192837482
```
Карточки жильцов с кнопкой «Написать в Telegram» будут падать прямо в группу Сергея!
